### 🧭 What I do

- **대용량 데이터 처리** — 쿼리 튜닝, 배치 성능 개선, 실행 계획부터 보는 습관
- **레거시 현대화** — 오래 운영된 서비스를 테스트로 감싸고, 작게 쪼개서, 안전하게 바꾸기
- **보안 대응** — 인증·인가, 입력 검증, 민감정보 처리를 *기능이 아닌 기본값*으로
- **협업** — 기술 도입은 데이터로 설득하고, 끝까지 운영으로 책임지기
